# /marketing-teardown

Analyze competitor growth trajectories, traffic shifts, messaging evolution, and funnel acquisition channels using public signals and data evidence.

## Usage

```bash
/marketing-teardown competitor.com
/marketing-teardown competitor.com --mode quick
/marketing-teardown competitor.com --mode funnel-hack
/marketing-teardown competitor.com --mode content
```

## Evidence Standard

- **Observed vs Inferred**: Explicitly label verified observations from public web/DNS/archives vs inferred marketing plays.
- **Actionable Plays**: Output dated chronological moves paired with concrete action items routed to relevant execution skills.
